# PumpPOS Mobile

Flutter application for Android and iOS. The app shares PumpPOS staff accounts,
permissions, branches, dashboard, sales, products, payments, and shifts through
Supabase.

Run checks from the repository root with `npm run mobile:check`.

Setup, build, signing, and current migration scope are documented in
[`../docs/flutter-mobile-development.md`](../docs/flutter-mobile-development.md).
