# เครดิตน้ำมัน

## เปิดบัญชีและบันทึกขาย

1. สร้างข้อมูลผู้ซื้อใน **ลูกค้าธุรกิจ** ตรวจตัวผู้ซื้อและผู้มีอำนาจลงนาม แล้วตกลงเงื่อนไขและลงนามในสัญญาซื้อเชื่อ
2. ผู้ดูแลระบบหรือผู้จัดการสาขาเปิด **ลูกหนี้เครดิต → รายละเอียด → จัดการเครดิต** บันทึกวงเงินค้างรวม จำนวนวันปฏิทินนับจากวันส่งมอบ วันที่ลงนาม และเลขอ้างอิงเอกสารจริง
3. พนักงานตรวจสถานะเครดิตในหน้าขายก่อนส่งมอบน้ำมัน เมื่อรับลายเซ็นผู้รับที่มีสิทธิแล้ว ให้กรอกเลขอ้างอิงใบรับน้ำมันในบิลขายเชื่อ ระบบบันทึกสัญญา เลขใบรับ และวันครบกำหนดจากเวลาไทยของเซิร์ฟเวอร์
4. ระบบตรวจวงเงินและยอดเกินกำหนดทุกครั้งที่บันทึกขายเชื่อในสาขานั้น ผู้จัดการพักเครดิตได้พร้อมบันทึกเหตุผล การแก้เงื่อนไขใช้กับบิลหลังอนุมัติ
5. เมื่อตรวจว่าได้รับเงินจริง ให้บันทึกเลขอ้างอิงและเลือกบิลตามที่ผู้ชำระระบุ ถ้าไม่ระบุ ระบบแสดงยอดตามลำดับวันขายเก่าก่อน ให้กระทบยอดตามสัญญาและหลักฐานจริงก่อนส่งหนังสือหรือใช้ในคดี การกลับรายการเก็บรายการเดิมและเหตุผลไว้ในแฟ้ม
6. บิลขายเชื่อเก็บประวัติไว้ผ่านการยกเลิกโดยผู้ดูแลระบบ การยกเลิกบิลที่มีเงินชำระแล้วต้องกระทบยอดและแก้รายการรับชำระตามหลักฐานจริงก่อน

วงเงินและการอนุมัติแยกตามสาขา บัญชีที่มีประวัติขายเชื่อก่อน migration อยู่ในสถานะ **เครดิตเดิม** พร้อมวงเงินเดิมเพื่อให้ขายและรับชำระได้ต่อเนื่อง ให้ตรวจสัญญาและอนุมัติบัญชีเหล่านี้เมื่อพร้อม บิลเดิมที่ไม่มีวันครบกำหนดแสดงเป็น **รอตรวจหลักฐาน** และแยกจากยอดเกินกำหนดของระบบ

## เอกสารที่ใช้

| ช่วง | เอกสาร |
| --- | --- |
| สมัครและตรวจตัวผู้ซื้อ | ใบสมัคร FC01 หลักฐานยืนยันตัวผู้ซื้อเท่าที่จำเป็น และใบตรวจเอกสาร/อนุมัติ FC02 สำหรับนิติบุคคลให้ตรวจหนังสือรับรอง เงื่อนไขลงนาม ตราประทับเมื่อกำหนด และหนังสือมอบอำนาจเมื่อใช้ผู้แทน |
| ทำข้อตกลง | สัญญาซื้อขายน้ำมันแบบเครดิต FC03 รายชื่อรถและผู้มีสิทธิรับน้ำมัน FC04 และหลักฐานแจ้งการใช้ข้อมูลส่วนบุคคล FC12 ระบุวงเงิน วันครบกำหนด วิธีชำระและตัดยอด วิธีวางบิล สิทธิพักเครดิต และช่องทางติดต่อไว้ในข้อตกลง |
| หลักประกันตามที่ตกลง | บันทึกรับเงินประกัน FC10 หรือสัญญาค้ำประกัน FC11 ให้ทนายตรวจรูปแบบ วงเงิน ระยะเวลา และหน้าที่บอกกล่าวก่อนใช้ |
| ส่งมอบและวางบิล | ใบสั่งเติมและใบรับน้ำมันที่ผู้มีสิทธิลงนาม FC05 ใบเสร็จ/ใบกำกับภาษีที่เกี่ยวข้อง ใบสรุปยอด FC06 ใบวางบิล FC07 และหลักฐานผู้รับวางบิล |
| รับเงินหรือแก้รายการ | ใบรับชำระ FC08 หลักฐานเงินเข้าหรือหลักฐานรับเงิน การจัดสรรตามบิล และบันทึกข้อโต้แย้ง/กลับรายการ FC22 |
| เกินกำหนดและส่งตรวจ | หนังสือแจ้งยอด FC13 หรือหนังสือบอกกล่าว FC14 พร้อมหลักฐานส่งและถึงผู้รับ FC17 บันทึกกระทบยอด/ผ่อนชำระ FC16 เมื่อคู่สัญญาตกลง แฟ้มหลักฐาน FC18 บันทึกข้อเท็จจริง FC19 ทะเบียนต้นฉบับ FC21 และหนังสือมอบอำนาจ FC24 เมื่อจำเป็น |

หน้าลูกหนี้พิมพ์สรุปยอด ร่างหนังสือแจ้งยอดเกินกำหนด และแฟ้มหลักฐานได้จากข้อมูลในระบบ เลขอ้างอิงมีไว้เชื่อมกับต้นฉบับที่กิจการเก็บรักษา ให้เก็บสำเนาบัตร สัญญาลงนาม ใบรับน้ำมัน และหลักฐานส่งหนังสือในที่ที่จำกัดสิทธิ์ ระบุเลขอ้างอิงในระบบและตรวจเอกสารแนบก่อนส่งภายนอก

## เมื่อลูกค้าเกินกำหนด

- **ติดตามหนี้ตามสัญญา** ตรวจยอดและข้อโต้แย้ง ส่งหนังสือผ่านช่องทางที่ตกลงอย่างเหมาะสม เก็บหลักฐานผู้รับและวันที่ส่ง แล้วพิจารณาไกล่เกลี่ยก่อนฟ้องหรือใช้สิทธิทางแพ่ง อายุความและเอกสารที่จะยื่นขึ้นกับข้อเท็จจริง ให้ทนายตรวจเป็นรายกรณี
- **มีเหตุสงสัยการหลอกลวง** บันทึกว่ามีการแสดงข้อมูลเท็จหรือปกปิดข้อเท็จจริงอย่างไร ผู้ขายส่งมอบน้ำมันเพราะเหตุใด และทราบเรื่องกับตัวผู้เกี่ยวข้องเมื่อใด แนบต้นฉบับให้ทนายหรือพนักงานสอบสวนตรวจว่ามีองค์ประกอบความผิดและควรร้องทุกข์อย่างไร คดีฉ้อโกงที่เป็นความผิดอันยอมความได้มีกำหนดร้องทุกข์ตามมาตรา 96 จึงควรรีบตรวจเมื่อมีข้อเท็จจริงลักษณะนี้
- **การติดตาม** ติดต่อผู้รับที่เกี่ยวข้อง เก็บหนังสือและหลักฐานเป็นส่วนตัว ใช้ถ้อยคำแจ้งยอดและขอชำระตามจริง หลีกเลี่ยงคำข่มขู่หรือการเปิดเผยหนี้แก่ผู้ไม่เกี่ยวข้อง

ระบบจัดทำร่างและบันทึกการติดตาม เจ้าของกิจการหรือผู้มีอำนาจตรวจและส่งหนังสือเอง การร้องทุกข์ให้ดำเนินการตามข้อเท็จจริงกับพนักงานสอบสวน

## อัปเกรดระบบ

ใช้ migration ของ Supabase หรือ Drizzle ตามฐานปลายทางผ่านขั้นตอน release ของโครงการ แล้วเผยแพร่ API และเว็บชุดเดียวกัน ทดสอบเปิดเครดิตและขายเชื่อด้วยบัญชีทดสอบของสาขาก่อนเปิดให้ใช้จริง ไฟล์สำรองแบบพกพารุ่น 2 รวมบัญชีและประวัติเครดิต การนำเข้าไฟล์รุ่น 1 สร้างบัญชีเครดิตเดิมตามประวัติบิลในไฟล์
