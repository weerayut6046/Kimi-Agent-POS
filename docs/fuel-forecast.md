# วางแผนสั่งน้ำมัน

เปิดเมนู **วางแผนสั่งน้ำมัน** หรือ `/stock/forecast` เพื่อดูว่าถังแต่ละถังเหลือขายประมาณกี่วัน ควรสั่งภายในวันใด และควรสั่งประมาณกี่ลิตร โดยใช้สต๊อกปัจจุบันกับประวัติการใช้น้ำมันของสาขาที่เลือก

## วิธีใช้งาน

1. เลือกช่วงย้อนหลัง **7, 14, 30, 60 หรือ 90 วัน** ค่าเริ่มต้นคือ 30 วัน ระบบใช้วันเต็มตามเวลาไทย (`Asia/Bangkok`) จนถึงเมื่อวาน ไม่รวมวันนี้
2. อ่านข้อมูลรายถัง: น้ำมันคงเหลือ ลิตรเฉลี่ยต่อวัน จำนวนวันที่มีหลักฐาน วันคาดว่าจะหมด วันควรสั่ง วันส่งตามแผน และลิตรแนะนำให้สั่ง
3. ตรวจข้อความเตือนก่อนใช้ผลตัดสินใจ แล้วกด **อัปเดตข้อมูล** หลังปิดกะ เติมน้ำมัน หรือแก้ไขข้อมูลถัง
4. ผู้จัดการหรือผู้ดูแลระบบกด **ตั้งค่าแผน** ของแต่ละถังเพื่อปรับเงื่อนไขการสั่งน้ำมัน

| ค่ารายถัง                  | ค่าเริ่มต้น | ความหมาย                                                    |
| -------------------------- | ----------- | ----------------------------------------------------------- |
| ระยะเวลาส่งน้ำมัน          | 2 วัน       | เวลาตั้งแต่สั่งจนคาดว่าจะได้รับน้ำมัน                       |
| วันเผื่อสต๊อก              | 2 วัน       | สำรองเผื่อยอดขายหรือการส่งคลาดเคลื่อน                       |
| จำนวนวันสำรองหลังรับน้ำมัน | 7 วัน       | เป้าหมายปริมาณคงเหลือหลังรับน้ำมัน เทียบกับลิตรเฉลี่ยต่อวัน |

**จำนวนวันสำรองหลังรับน้ำมันต้องมากกว่าระยะเวลาส่งรวมกับวันเผื่อสต๊อก** เช่น ส่ง 2 วันและเผื่อ 2 วัน ต้องตั้งเป้าหมายมากกว่า 4 วัน

## อ่านผลอย่างไร

- **ยังมีเวลาวางแผน**: สต๊อกยังสูงกว่าจุดสั่งซื้อที่คำนวณจากระยะเวลาส่งและวันเผื่อ
- **ควรสั่งวันนี้**: ถึงวันที่ควรสั่งตามแผนแล้ว แม้สต๊อกอาจยังสูงกว่าจุดสั่งซื้อเล็กน้อยในช่วงต้นวัน
- **เสี่ยงหมดก่อนรถส่งถึง**: ปริมาณคงเหลืออาจไม่พอสำหรับระยะเวลาส่ง ควรตรวจสต๊อกและประสานผู้ส่งทันที
- **ยังคาดการณ์ไม่ได้**: ระบบไม่แสดงวันและปริมาณสั่งซื้อเป็นข้อเสนอที่เชื่อถือได้จนกว่าประวัติจะพร้อมหรือแก้ข้อมูลที่ผิดแล้ว

วันส่งและลิตรสั่งซื้อเป็นแผนประมาณการตามวันควรสั่ง ระยะเวลาส่ง และปริมาณที่คาดว่าจะเหลือเมื่อรับน้ำมัน ลิตรแนะนำจำกัดตามพื้นที่ว่างของถัง โดยเผื่อรถมาถึงช่วงต้นของวันที่แสดง หากความจุไม่พอสำหรับเป้าหมายที่ตั้งไว้ ระบบจะแจ้งเตือน ผลนี้ยังไม่รวมของที่สั่งไว้และรอรับ และการเปิดหน้านี้ไม่ได้สร้างใบสั่งซื้อหรือจองรถส่งน้ำมัน

## ข้อมูลและข้อจำกัด

- แหล่งหลักคือลิตรจากผลต่างมิเตอร์เปิด–ปิดของ **กะที่ปิดแล้ว** รวมตามวันปิดกะ ไม่บวกยอด POS ที่รวมอยู่ในมิเตอร์ซ้ำ ยอด POS ที่ไม่มีมิเตอร์ประกอบยังไม่ยืนยันการใช้น้ำมันรายถังสำหรับการคาดการณ์
- ต้องมีหลักฐานในช่วงที่เลือกอย่างน้อย **7 วัน** และประวัติต้องครอบคลุมตั้งแต่ต้นช่วง หรือมีประวัติมิเตอร์ก่อนช่วงนั้น การเริ่มเก็บข้อมูลกลางช่วง 30 วันไม่ถือว่าวันก่อนเริ่มเก็บเป็นวันขายศูนย์ ควรเลือกช่วงสั้นลงเมื่อประวัติพร้อม
- ค่าเฉลี่ยหารด้วย **ทุกวันในช่วงที่เลือก รวมวันยอดศูนย์** ไม่หารเฉพาะวันที่ขายได้ เพื่อไม่ทำให้อัตราการใช้น้ำมันสูงเกินจริง หากยอดสุทธิไม่เป็นบวกจะประมาณวันหมดไม่ได้
- เมื่อมีกะเปิด สต๊อกในระบบยังไม่หักผลต่างมิเตอร์ของกะนั้นจนกว่าจะปิดกะ ตัวเลขคงเหลือและวันที่คาดการณ์จึงอาจสูงกว่าสภาพจริง
- ประวัติใช้การผูกหัวจ่ายกับถังและชนิดน้ำมัน **ปัจจุบัน** หากเคยเปลี่ยนการผูกหัวจ่ายควรตรวจประวัติก่อนใช้ผล
- มิเตอร์ไม่ครบ ค่าถอยหลัง รายการซ้ำ กะซ้อนกัน ยอดรวมไม่ตรง ถังที่จัดสรรยอดไม่ได้ หรือความจุและสต๊อกไม่ถูกต้อง จะมีคำเตือนและงดผลคาดการณ์ของถังที่ได้รับผลกระทบ

## สิทธิ์และการตั้งค่า

เมนูนี้ใช้ permission key **`fuel_forecast`** แยกจาก `stock` ทั้ง route และ API ตรวจสิทธิ์เดียวกัน ค่าเริ่มต้นเปิดให้อ่านได้ทุกบทบาท แต่บัญชีที่กำหนดสิทธิ์เองต้องได้รับสิทธิ์นี้ด้วย การมีสิทธิ์สต๊อกอย่างเดียวไม่เปิดเมนูวางแผนสั่งน้ำมัน

พนักงานอ่านผลได้ ผู้จัดการและผู้ดูแลระบบที่มีสิทธิ์เมนูบันทึกค่ารายถังได้ ผู้ดูแลระบบคงสิทธิ์ทุกเมนูเสมอ ค่าถูกเก็บแยกตามสาขาใน settings เดิม (`fuel_forecast_config`) ฟังก์ชันนี้ไม่ต้องเพิ่มตารางหรือรัน migration
