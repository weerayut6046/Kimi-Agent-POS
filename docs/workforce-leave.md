# การลาพนักงาน

เปิด **พนักงานและตารางงาน → การลา** พนักงานเลือกประเภท วันเริ่มและวันสิ้นสุด และหมายเหตุ แล้วติดตามผลจาก **ใบลาของฉัน** หากมีกะของคนอื่นเปิดอยู่ ให้เลือก **เปิดใบลาของฉัน** จากหน้าสถานะกะได้ด้วย ใบลาที่รออนุมัติยกเลิกเองได้

ผู้จัดการและแอดมินดูใบลาในสาขาปัจจุบันที่ **ใบลาทีม** ระบบแนะนำจำนวนวันใช้สิทธิ์จากวันที่มีตารางงาน หลายกะในวันเดียวกันนับเป็นวันเดียว ผู้อนุมัติตรวจวันหยุดและปรับจำนวนวันได้ หากเกินยอดสิทธิ์ที่ตั้งให้บันทึกเหตุผลประกอบ ผู้อนุมัติสามารถปฏิเสธหรือยกเลิกการอนุมัติพร้อมเหตุผล ระบบเก็บชื่อและเวลาพิจารณาไว้

แอดมินตั้งยอดสิทธิ์แยกพนักงาน ประเภท สาขา และปีปฏิทิน ใช้ **ตั้งสิทธิ์วันลา** ในหน้าใบลาทีม ยอดที่ใช้มาจากใบลาที่อนุมัติในระบบ ช่วงลาข้ามปีให้ยื่นแยกตามปี ใช้สิทธิ์เป็นจำนวนเต็มวัน

ใบลาที่อนุมัติจะแสดงบนกะเดิมและกันการจัดกะใหม่หรือสลับกะทับวันลา ผู้ดูแลเปลี่ยนพนักงานผู้รับกะได้ การอนุมัติใบลาเก็บตารางกะเดิมและแยกจากการพิจารณาค่าจ้าง ให้ผู้ดูแลตรวจตารางงานและเงินเดือนตามกติกาของกิจการ บันทึกเวลาเข้าทำงานเดิมและสถานะลาเดิมยังอ่านได้ตามปกติ

ก่อนปล่อยใช้งานจริงให้รัน migration ของ Supabase หรือ Drizzle ตามฐานข้อมูลของโครงการ แล้วเผยแพร่เว็บและ API คู่กัน ไฟล์สำรองแบบพกพารุ่น 2 รวมใบลาและสิทธิ์วันลา และยังเปิดไฟล์สำรองรุ่น 1 ได้
