# การเข้าสู่ระบบและเปิดกะของพนักงาน

พนักงานเข้าสู่ระบบด้วยชื่อผู้ใช้และ PIN หรือ passkey ที่ลงทะเบียนไว้ จากนั้นเปิดกะได้ตามสิทธิ์และกติกาของระบบ การล็อกอินไม่บันทึกเวลาเข้า–ออกงาน และการเปิดกะไม่ต้องยืนยันผ่านกล้อง

ระบบถอดการลงทะเบียนและสแกนใบหน้าออกจากหน้าเว็บ มือถือ และ API แล้ว รวมถึงขั้นตอนสร้างเจ้าของและเพิ่มพนักงาน ประวัติลงเวลาเดิมยังคงอยู่เพื่อใช้ตรวจสอบย้อนหลัง

## อัปเดตฐานข้อมูล

หลังทดสอบใน staging ให้เผยแพร่ frontend และ API รุ่นนี้พร้อมกันก่อน แล้วใช้ release workflow ของโครงการเพื่อรัน [`20261008001813_remove_employee_face_profiles.sql`](../supabase/migrations/20261008001813_remove_employee_face_profiles.sql) บน Supabase หรือ [`0034_special_spyke.sql`](../web/db/migrations-postgres/0034_special_spyke.sql) สำหรับ PostgreSQL local/self-hosted เลือกชุด migration ที่ฐานข้อมูลนั้นใช้อยู่ โค้ดรุ่นเดิมยังอ่านตารางข้อมูลใบหน้า จึงต้องเปลี่ยนโค้ดก่อนลบตาราง

Migration ลบตารางข้อมูลใบหน้าที่เข้ารหัส `pos.employee_face_profiles` โดยคงบัญชี PIN สิทธิ์ passkey และประวัติลงเวลาเดิมไว้ ไม่ต้องสร้างบัญชีหรือตั้ง PIN ใหม่
