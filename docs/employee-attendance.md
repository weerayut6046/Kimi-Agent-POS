# ระบบลงเวลาเข้า–ออกงาน

ฟังก์ชันสแกนใบหน้าเพื่อบันทึกเวลาเข้า–ออกงานและ QR ประจำสาขาถูกถอดออกจาก POS แล้ว ระบบลงเวลาภายนอกจะดำเนินการแยกต่างหาก

POS ยังคงใช้ใบหน้าเพื่อ **เข้าสู่ระบบ** เท่านั้น พนักงานกรอกชื่อผู้ใช้และ PIN แล้วสแกนใบหน้า ผู้ดูแลระบบหรือผู้จัดการลงทะเบียนใบหน้าได้ที่ `/workforce/face-enrollment` การเข้าสู่ระบบไม่สร้างรายการลงเวลา และการเปิดกะ POS ไม่ต้องมีรายการสแกนเข้างาน

ตารางลงเวลาเดิมในฐานข้อมูลยังคงอยู่เพื่อรักษาข้อมูลย้อนหลัง การถอด UI และ API ไม่ได้ลบข้อมูลเดิมหรือสร้าง migration สำหรับลบตาราง
