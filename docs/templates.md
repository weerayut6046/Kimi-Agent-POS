# เทมเพลตหน้าจอ PumpPOS

ระบบเลือกเทมเพลตที่รวมอยู่ในแอปได้จาก **ตั้งค่าระบบ → รูปแบบหน้าจอ** โดยบัญชีผู้ดูแลระบบ (`admin`) ที่มีสิทธิ์เมนูตั้งค่า การเปลี่ยนเทมเพลตมีการตรวจสิทธิ์ที่ API ด้วย

## การเลือกเทมเพลต

1. ตรวจสอบสาขาที่ใช้งานจากตัวเลือกสาขาในแถบเมนู
2. เปิดหน้าตั้งค่าและเลือกแท็บรูปแบบหน้าจอ
3. เลือก **PumpPOS** หรือ **TailAdmin** ระบบบันทึกและใช้รูปแบบที่เลือกให้กับสาขาปัจจุบัน
4. เลือกชุดสีที่ต้องการในหน้าเดียวกัน

เทมเพลตเป็นค่าของสาขา ไม่ใช่ค่าของบัญชีผู้ใช้ ผู้ใช้ที่เปิดสาขาเดียวกันจะได้รับรูปแบบเดียวกัน เมื่อเปลี่ยนสาขาระบบจะอ่านการตั้งค่าของสาขาใหม่ สาขาที่ยังไม่ได้ตั้งค่าจะใช้ PumpPOS และชุดสี Command Center

| เทมเพลต | รูปแบบ |
| --- | --- |
| PumpPOS | หน้าจอมาตรฐานของระบบ พร้อมแถบเมนูสีเข้มตามชุดสีที่เลือก |
| TailAdmin | แถบเมนูและส่วนหัวสีขาว พื้นหลังเทาอ่อน เส้นขอบสีเทา การ์ดมุมโค้ง 16 พิกเซล และแถบเมนูเดสก์ท็อปกว้าง 290 พิกเซล |

## เทมเพลตกับชุดสี

ค่าทั้งสองเลือกแยกกันได้ โดยเทมเพลตกำหนดลักษณะพื้นผิว เมนู และขนาด ส่วนชุดสีกำหนดสีหลักของปุ่มและรายการที่เลือก

สำหรับ TailAdmin ชุดสี **Command Center** ใช้สีน้ำเงิน `#465fff` ตามต้นฉบับ ส่วน Calm Counter, Thai Modern, Industrial Pro และ Ocean Blue ยังคงสีหลักของชุดสีนั้น สีแจ้งเตือนและสถานะของงานยังใช้ความหมายเดิม

รูปแบบนี้ใช้กับหน้าจอแอปหลังเข้าสู่ระบบบนเว็บและแอปเดสก์ท็อปที่ใช้หน้าเว็บชุดเดียวกัน หน้าเข้าสู่ระบบและแอป Flutter ใช้หน้าจอของตนเอง ส่วนใบเสร็จและเอกสารพิมพ์ยังใช้รูปแบบการพิมพ์เดิม

## ตารางและคอมโพเนนต์ใน TailAdmin

นอกจากแถบเมนูและส่วนหัว รูปแบบ TailAdmin ยังปรับคอมโพเนนต์ที่ใช้งานจริงของ PumpPOS ได้แก่ ตาราง การ์ด ปุ่ม ช่องกรอกข้อมูล ตัวเลือก แท็บ ป้ายสถานะ และกล่องโต้ตอบ

- ตารางใช้แถวแบบเรียบ เส้นแบ่งสีเทาอ่อน หัวตารางบนพื้นขาว และแผงตารางที่รวมชื่อ จำนวนรายการ ปุ่ม และตัวกรองไว้ด้านบน ตารางยังเลื่อนแนวนอนบนมือถือได้
- ปุ่มและช่องกรอกข้อมูลมาตรฐานใช้มุมโค้ง 8 พิกเซล ช่องกรอกข้อมูลมีพื้นขาวและขอบ `#d0d5dd` พร้อมกรอบโฟกัสตามชุดสีที่เลือก
- ตัวเลือกและเมนูใช้พื้นผิวและเงาอ่อน ส่วนกล่องโต้ตอบยังใช้ขนาด การเลื่อน และการจัดการโฟกัสของ Radix เดิม
- ป้ายสถานะสำเร็จ คำเตือน และสถานะทั่วไปใช้พื้นสีอ่อนตามความหมาย การลบ ข้อผิดพลาด และช่องกรอกข้อมูลที่ไม่ถูกต้องยังคงสีแจ้งเตือนเดิม
- ช่องกรอกข้อมูลที่กำหนดขนาดเล็กเฉพาะงานยังใช้ขนาดเดิม ปุ่มและรายการเมนูมาตรฐานบนมือถือมีพื้นที่กดอย่างน้อย 44 พิกเซล

การปรับนี้เปลี่ยนรูปแบบของคอมโพเนนต์ที่มีอยู่ในระบบ โดยยังใช้ข้อมูล การเรียงลำดับ การค้นหา การตรวจสอบข้อมูล และระบบสิทธิ์ของ PumpPOS ตามเดิม

## การแจ้งเตือน

เมื่อเลือก TailAdmin ข้อความแจ้งผลแบบ Toast แถบแจ้งเตือนในหน้าและแบบฟอร์ม แถบออฟไลน์/รอซิงก์ กระดิ่งสต๊อกต่ำ และกล่องยืนยันใช้รูปแบบที่สอดคล้องกัน โดยแยกสีสำเร็จ คำเตือน ข้อผิดพลาด และข้อมูลทั่วไป ข้อความยาวสามารถขึ้นบรรทัดใหม่บนมือถือได้

Toast ยังคงใช้เวลาปิด การปิดด้วยผู้ใช้ ปุ่มดำเนินการ และสถานะกำลังทำงานของ Sonner เดิม กระดิ่งแสดงข้อมูลถัง/สินค้าที่ต่ำกว่าเกณฑ์ของ POS และกล่องยืนยันยังใช้ Radix โดยการยกเลิกไม่ดำเนินรายการ

ข้อความตรวจสอบช่องกรอกยังเป็นข้อความสั้นใกล้ช่องนั้น ส่วนสถานะในตารางและตัวเลขสรุปยังใช้คอมโพเนนต์ของตนเอง รูปแบบการแจ้งเตือนจำกัดเฉพาะหน้าจอและไม่เปลี่ยนเอกสารพิมพ์

## เทมเพลตภายนอก

รุ่นนี้รองรับเทมเพลตที่นำมาปรับและรวมไว้ในโครงการแล้ว ได้แก่ PumpPOS และ TailAdmin ยังไม่มีช่องอัปโหลด ZIP, HTML หรือ CSS เพื่อเพิ่มเทมเพลตใหม่จากหน้าตั้งค่า

การเพิ่มเทมเพลตอื่นต้องตรวจสิทธิ์การใช้งาน ปรับให้เข้ากับคอมโพเนนต์และระบบสิทธิ์ของ PumpPOS รวมถึงทดสอบหน้าจอและการพิมพ์ก่อนรวมไว้ในแอป เทมเพลต React สำเร็จรูปที่มีหน้าเข้าสู่ระบบหรือแดชบอร์ดตัวอย่างต้องเชื่อมเข้ากับข้อมูลและการทำงานของ PumpPOS ด้วย

## รายละเอียดสำหรับผู้พัฒนา

- `app_template` เก็บค่า `pumppos` หรือ `tailadmin` ในการตั้งค่าของแต่ละสาขา
- `app_theme` เก็บชุดสีที่เลือก โดยใช้ทะเบียนและตัวตรวจค่าจาก `web/contracts/settings.ts`
- `AppThemeSync` อ่านค่าตั้งค่าของสาขาแล้วกำหนด `data-pos-template` และ `data-pos-theme` บน `<html>` และคืนเทมเพลตเป็น PumpPOS เมื่อออกจากพื้นที่แอปที่เข้าสู่ระบบแล้ว
- CSS ของ TailAdmin อยู่ใน `web/src/styles/tailadmin.css` และทำงานเฉพาะสื่อหน้าจอ (`screen`)
- รูปแบบคอมโพเนนต์อยู่ใน `web/src/styles/tailadmin-components.css` ใช้ `data-slot`, `data-variant` และคลาสเริ่มต้นเป็นเงื่อนไข เพื่อคงสีสถานะและขนาดที่แต่ละหน้ากำหนดไว้ แผงตารางใช้คลาส `data-table-panel` และป้ายสถานะใช้ `data-status="success"`, `warning` หรือ `neutral`
- การแจ้งเตือนอยู่ใน `web/src/styles/tailadmin-notifications.css` ข้อความในหน้าใช้ `data-slot="notice"` และ `data-tone` ค่า `success`, `warning`, `error` หรือ `info` ตามความหมายของข้อความ แถบเต็มความกว้างใช้ `data-notice-layout="bar"` ส่วน `Alert` กลางรองรับ variant เหล่านี้ด้วย
- คอมโพเนนต์ที่ใช้คลาสกำหนดเองยังคงรูปแบบที่หน้านั้นระบุ การปรับเทมเพลตใหม่ควรตรวจช่องกรอกข้อมูลผิดพลาด ปุ่มที่ปิดใช้งาน การใช้คีย์บอร์ด และตารางบนจอเล็กด้วย
- การเพิ่มเทมเพลตต้องเพิ่มตัวเลือกในทะเบียนกลาง ตรวจสิทธิ์เมนูและ API และคงข้อความใบอนุญาตของแหล่งที่มาไว้เมื่อมีการดัดแปลงหรือแจกจ่าย
